# URANO Spatial contracts

These JSON Schemas define the boundary between scientific state, interaction, spatial projection and external capabilities.

- `research-state.schema.json`: canonical investigation state owned by URANO.
- `spatial-scene-spec.schema.json`: renderer projection contract; never evidence by itself.
- `interaction-intent.schema.json`: modality-neutral user/system interaction events.
- `capability-contract.schema.json`: API/MCP/local bridge/driver capability declaration and runtime status boundary.

Schemas are versioned independently from renderers and providers.
