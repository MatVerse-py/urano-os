# Plugin-assisted review

This branch was refined using available external tooling as advisory/validation surfaces, while keeping GitHub as the canonical versioned source.

- Figma connector: authenticated, but current Starter/View seat limits direct editing; no design state was claimed as written.
- Replit connector: app creation attempted but blocked because the connected account requires an active subscription; no Replit runtime was claimed.
- GitHub connector: used to inspect the canonical `urano-os` repository, create this isolated feature branch, and add the spatial contracts and UX invariants.

The goal is to improve URANO without allowing any external platform to become an authority over scientific state, release decisions, or sovereignty policy.
