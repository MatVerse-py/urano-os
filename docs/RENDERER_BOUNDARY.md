# Renderer boundary

A renderer receives `SpatialSceneSpec` and emits `InteractionIntent`.

A renderer MUST NOT:

- promote a claim or hypothesis;
- mutate evidence directly;
- mark a provider CONNECTED without runtime health evidence;
- bypass sovereignty or capability policy;
- reinterpret a generative metaphor as an observed result.

A renderer MAY:

- select PAPER/SPACE presentation;
- project entity positions, morphology and whirl dynamics;
- expose capability status already computed by the runtime;
- normalize platform-specific input into `InteractionIntent`;
- render deterministic scenes from the same source state and seed.
