# URANO OSX — Spatial UX principles

1. The home starts in PRESENCE: no automatic external calls, no demo research, no hidden costs.
2. The Cube is a state projection, not a logo or proof source.
3. The Living Notebook is the causal timeline; spatial visuals are alternate projections of the same investigation.
4. PAPER and SPACE are perceptual modes, not separate products.
5. Interface complexity emerges only when relevant to the current intent.
6. Generative metaphors, semantic maps and observed results must remain visibly distinct epistemic classes.
7. Model providers are capabilities. Cassandra is the interpretation function; URANO must never be branded as one provider's core.
8. SOVEREIGN means LOCAL-only. External capabilities require a policy transition or explicit scoped authorization.
9. Model Trace shows observable operational trajectory, never private chain-of-thought.
10. Mouse, touch, gaze, hand, voice and controller inputs must normalize to InteractionIntent before affecting state.
